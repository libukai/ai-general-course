固定流程为技能重复使用 ​

当一项任务已经稳定做对，就不用下次再从头解释。把经过验证的任务约定和配合方式保存为技能（Skill），智能体才能在下一次拿到相似任务时稳定复用。

技能不只是一句提示词 ​

这里的技能（Skill）不是一段孤立的提示词，也不是一个工具本身；它把一类任务的流程、所需资料、工具调用规则和验收标准固定下来，再由运行框架按这些规则组织执行。

从技术上看，一个 Skill 就是一个独立、规范命名的文件夹。以“工作讨论会行动安排”为例，常见构成如下：

text
meeting-action-plan/
├── SKILL.md              # 必需：用途、适用条件、执行步骤与验收标准
├── references/           # 可选：业务规则、字段说明、范例等参考资料
├── scripts/              # 可选：可重复执行的脚本或工具调用逻辑
└── templates/            # 可选：任务、邮件、表格或报告的输出模板

智能体先根据名称和 SKILL.md 的简介发现合适的 Skill；需要时再读取其中的说明、资料、脚本或模板，不必把所有规则反复塞进每轮对话。

一项可复用的技能至少要说清五件事：

  1. 触发条件与目标：什么情况下启动，要完成哪一类任务。
  2. 输入材料与范围：默认读取哪些资料，哪些资料不能使用或需要补充。
  3. 执行流程与工具规则：先做什么、后做什么，需要调用哪些工具。
  4. 确认点与例外处理：遇到哪些情况必须停下来请人判断。
  5. 产出与验收标准：最终交付什么，以及怎样才算完成。

把跑通的协作流程转化为技能 ​

当你已经和智能体配合把一件事做顺了，不必从零编写。回看一次成功完成的任务，把“读取什么材料、按什么顺序做、哪里需要你确认、怎样检查结果”整理成技能说明，就能快速沉淀为可复用的 Skill。

以“把工作讨论会整理成行动安排”为例，技能可以规定：读取会议纪要和团队日历 → 提取行动项 → 核对时间冲突 → 生成任务草稿 → 按清单检查后返回。点播放，看核心内容怎样组合成一项可以重复使用的技能。

就绪

点播放：把任务材料、工作步骤和检查清单保存成一项技能。

任务材料

只读取本次工作讨论会的会议纪要、工作群和团队日历；负责人或期限不明确时，把原文和问题交给我。

工作步骤

先调用只读工具核对材料，再生成任务、日程和通知草稿；得到确认后才调用写入和发送工具。

检查清单

每项包含负责人、截止时间、下一步和出处；执行后返回任务链接、日程状态和消息发送结果。

如果不想从空白模板开始，可以调用 skill-creator（也可理解为“创建技能”的元技能）。把已跑通的任务过程、使用的材料、工具调用、人工确认点和验收标准交给它，它会帮助你整理成一份可继续修改的 Skill 初稿；初稿仍需通过同类真实任务试跑，再补全规则。

先用同类真实任务试跑，发现遗漏就补充规则；连续几次能按同一检查清单完成，再考虑将它用于更频繁的任务。写入、发送和提交等高影响动作仍可保留人工确认。

  1. 回看一次成功协作

    从真实完成的任务中提炼资料范围、步骤、确认点和验收标准。

  2. 整理成可复用规则

    把同一类任务的工作顺序和工具调用规则写成技能说明。

  3. 用同类任务试跑

    发现遗漏就补充规则；高影响动作仍可保留人工确认。

在智能体商店寻找合适的技能 ​

不必每次都自己创建。面对常见任务，可以先到智能体商店按任务类型寻找现成 Skill；选中前重点核对它需要读取的资料、会调用的工具、默认的执行范围，以及最终交付和确认方式是否与你的工作一致。
